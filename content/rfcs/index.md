# Requests for comments

An RFC proposes a convention or a design that more than one client would follow. Each is published on the official blyg, [blyg.blygger.org](https://blyg.blygger.org/), with a comment period. Like a technical note, an RFC constrains nothing. When its period closes it becomes a [technical note](/notes/).

**To comment,** respond to the RFC from your own blyg. A stub is a comment, a partial quote names the passage you are answering, and a fork of the pinned version is a counter-proposal. Without a blyg, comment on the RFC's GitHub issue.
